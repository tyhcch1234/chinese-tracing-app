# 中文描紅練習（iPhone 網頁版原型）

給香港小一至小三學生練寫正體字的描紅 app 原型。
以單一 HTML 檔製作，**無需 Mac、無需安裝**，直接在 iPhone 的 Safari 開啟即可使用。

## 在 iPhone 上開啟

1. 把 `index.html` 放到一個免費網頁空間（最簡單：GitHub Pages 或 Netlify Drop）。
2. 用 iPhone 的 Safari 開啟該網址。
3. 點「分享」→「加入主畫面」，就會像 app 一樣出現在桌面、全螢幕開啟。

## 目前功能（第二版）

- **約 300 個**小一至小三常用正體字（302 個不重複字，分 18 個分類，每個字附粵拼）
- **分類選字**：先選分類（數字、身體、家人、動物、植物、自然、顏色與形狀、方向與位置、動作、食物、學校、形容詞、時間、交通、衣物、家居、感覺與心情、常用字），再點選要練習的字
- 田字格 + 淺紅色描紅範字
- 手指 / Apple Pencil 書寫（支援多點觸控）
- 「檢查」：比對你寫的筆跡與範字的**覆蓋率**與**準確度**，給 0–100 分與鼓勵語
- **得分 ≥70 分**時，用粵語播放「波仔，叻仔，繼續努力！」（依賴裝置語音，iOS 對粵語語音支援有限，屬測試功能）
- 「讀音」：粵語讀音（同上，依賴裝置語音）
- 「清除 / 上一個 / 下一個」切換（在目前分類內切換）

## 尚未包含（後續版本方向）

- 筆順動畫示範（需要引入 Make Me a Hanzi 的筆順資料）
- 筆順正確與否的判斷（目前只判斷形狀與位置，不判斷筆順）
- 分級字庫、闖關/星星獎勵、錯字記錄
- App Store 上架（.ipa）

## 成為真正的 App Store app

網頁版是「先做出來給你試」的最快路徑。要上架 App Store（.ipa），因為沒有 Mac，可行路線：

1. **Flutter 重寫 + 雲端編譯**：用 Codemagic 或 Expo EAS Build 在沒有 Mac 的情況下編譯出 `.ipa`。
2. **借/租一台 Mac**：用 Xcode 打包上架（需要 Apple 開發者帳號，US$99/年）。

## 注意

- 請用裝有中文字型的裝置開啟（iPhone / 大部分手機均內建）。
- 「檢查」功能會把筆跡與範字做像素比對，比較適合「描紅」型練習；自由默寫的正確率會偏低。
